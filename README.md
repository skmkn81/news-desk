# MY NEWS DESK

관심 분야 뉴스를 한곳에 모아 보는 개인 대시보드입니다.

**탭:** M&A · K-푸드 · 한국 정치 · 한국 경제 · 세계 뉴스

## 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 (대시보드) |
| `수집.ps1` | RSS에서 뉴스를 모으는 프로그램 |
| `설정.json` | 탭과 뉴스 출처 목록 — 검색어를 바꾸려면 여기 |
| `기획.md` | 어떤 결정을 왜 했는지 기록 |
| `data/news.js` | 화면이 읽는 기사 데이터 |
| `data/status.json` | 출처별 마지막 성공 시각 |

## 자동 수집

`.github/workflows/collect.yml` 이 **매일 아침 7시, 저녁 6시(한국시간)** 에
스스로 뉴스를 모아서 페이지를 갱신합니다. PC를 켜둘 필요가 없습니다.

즉시 돌려보려면: 저장소 상단 **Actions** 탭 → **뉴스 자동 수집** → **Run workflow**

## 내 컴퓨터에서 쓸 때

`수집.ps1` 오른쪽 클릭 → **PowerShell에서 실행** → 끝나면 `index.html` 열기 (또는 F5)
